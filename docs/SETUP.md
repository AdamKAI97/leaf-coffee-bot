# Настройка бесплатных сервисов

Нужно создать 3 аккаунта. Везде проще всего входить через GitHub-аккаунт — так сервис сразу увидит ваши репозитории.

## 1. Neon (база данных)

1. Откройте https://neon.tech
2. Нажмите **Sign up** → войдите через GitHub.
3. Нажмите **Create a project**, название — `leaf-coffee`.
4. Регион выберите ближайший (например, Europe).
5. После создания на странице проекта найдите **Connection string** (строка вида `postgresql://...`).
6. Скопируйте её — это будет значение `DATABASE_URL`, пришлите мне, я подставлю в конфиг Render.

## 2. Render (backend + бот)

1. Откройте https://render.com
2. **Sign up** → войдите через GitHub, дайте доступ к репозиторию `leaf-coffee-bot`.
3. На дашборде нажмите **New** → **Web Service**.
4. Выберите репозиторий `leaf-coffee-bot`.
5. Настройки (когда дойдём до деплоя, я скажу точные значения Build/Start Command и Root Directory — на этом этапе просто создайте аккаунт, деплоить будем позже).

## 3. Vercel (Mini App + админка)

1. Откройте https://vercel.com
2. **Sign up** → войдите через GitHub, дайте доступ к репозиторию `leaf-coffee-bot`.
3. Аккаунт создан — сами проекты (Mini App, админка) подключим, когда будет готов код фронтенда.

---

Как только Neon-проект создан — пришлите **Connection string**, продолжим с Этапа 1 (наполнение меню, бот, API).
