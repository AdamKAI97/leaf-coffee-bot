# Архитектура Leaf Coffee

## Бренд

- Логотип: `docs/assets/logo.png`
- Основной цвет: `#A8D3CC`
- Тёмный/текстовый цвет: `#333436`

## Стек

- **backend/** — Node.js + TypeScript + Express + Prisma ORM. Здесь же живёт Telegram-бот (Telegraf) — один процесс, один деплой на Render.
- **miniapp/** — Next.js, открывается внутри Telegram как Mini App. Весь процесс заказа: меню, варианты, корзина, оплата.
- **admin/** — Next.js, отдельная веб-панель для владельца кофейни: меню, филиалы, заказы, лояльность.
- **База данных** — PostgreSQL на Neon, схема описана в `backend/prisma/schema.prisma`.

## Почему так

- Бот и API в одном процессе — экономит один бесплатный сервис на Render (бесплатный тариф даёт ограниченное количество сервисов).
- Mini App и админка — раздельные Next.js-проекты, чтобы не путать логику клиента и персонала.
- Все переводимые тексты (названия товаров, категорий, филиалов) хранятся как отдельные поля `*_ru`, `*_uz`, `*_en` прямо в таблицах — просто и работает для 30+ позиций.

## Схема данных (кратко)

- `Branch` — филиалы (адрес, часы работы, гео).
- `Customer` — клиент бота (Telegram ID, язык, баллы лояльности).
- `MenuCategory` / `MenuItem` — меню.
- `VariantGroup` / `VariantOption` — размер/температура/декаф/сахар, привязка к товару через `MenuItemVariantGroup`.
- `Order` / `OrderItem` / `OrderItemVariant` — заказ и его состав.
- `OrderStatusLog` — история статусов заказа.
- `Promotion` — скидки, промокоды, розыгрыши.
- `LoyaltyTransaction` — начисление/списание баллов.
